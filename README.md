# pasport-watcher

Инструменты для слежения за талонами (местами в электронной очереди) на сайтах
паспортных сервисных центров вида `<город>.pasport.org.ua` (ДП «Документ» —
Прага, Валенсия и другие) и оповещения, когда места появляются или снова
пропадают.

Два независимых инструмента в этом репозитории — берите тот, что вам нужен:

| | `notifier.py` | `watch.py` |
|---|---|---|
| Для чего | Публикует в Telegram-канал для всех подписчиков | Личный сигнал лично вам, чтобы успеть кликнуть самому |
| Вход через Дія/BankID | Не нужен (страница со списком дат видна без входа) | Нужен (использует ваш уже залогиненный Chrome) |
| Уведомление | Сообщение в Telegram-канал/чат | Звук + всплывающее окно на экране |
| Можно следить за несколькими городами сразу | Да, из одного конфига | Один сайт за раз |
| Автозапуск при старте Windows | Есть (`install_autostart.ps1`) | Нет |

Оба — **только Windows** (используют `winsound`, и headless-браузер на этих
сайтах Cloudflare блокирует — см. ниже, — поэтому нужен видимый рабочий стол).

## notifier.py — публикация в Telegram-канал

### Важный технический момент

Сайты защищены Cloudflare. Обычный `fetch`/`curl` и headless-браузер
получают 403/429 ("Performing security verification") — проверено вживую.
Обычный (НЕ headless) Chromium страницу открывает нормально. Поэтому
`notifier.py` запускает настоящий, не headless Chromium, но уводит его окно
за пределы экрана (`--window-position=-32000,-32000`), чтобы оно не мешало.
В диспетчере задач будет виден процесс `chrome.exe` — это нормально.

### Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

### Настройка

1. Создайте Telegram-бота: [@BotFather](https://t.me/BotFather) → `/newbot`,
   сохраните токен.
2. Добавьте бота **администратором** в свой канал (право публикации сообщений).
3. Узнайте `chat_id` канала — публичный: `@имя_канала`; приватный: перешлите
   сообщение из канала боту [@userinfobot](https://t.me/userinfobot).
4. Скопируйте `notifier_config.example.json` → `notifier_config.json` и
   заполните: `telegram_bot_token`, `telegram_chat_id`.
5. **Под другой город**: поменяйте `watch_url` на страницу электронной
   очереди нужного города (`https://<город>.pasport.org.ua/solutions/e-queue`),
   затем откалибруйте `unavailable_phrases` — откройте эту страницу в браузере
   и скопируйте ТОЧНУЮ фразу, которая написана, когда мест нет (обычно что-то
   вроде "Наразі всі місця зайняті" / "спробуйте в інший час"). `required_phrases`
   (по умолчанию `["документ"]`) — общая "опознавательная" фраза сайта,
   которая ДОЛЖНА быть на странице независимо от наличия мест; если для
   вашего города она не подходит — замените на что-то, что всегда есть на
   реальной странице (нужна для защиты от ложных срабатываний на
   Cloudflare-проверках, см. ниже).
6. Можно следить сразу за несколькими городами — добавьте ещё один объект в
   массив `targets` (свой `watch_url`, свои `unavailable_phrases`, свой или
   тот же `telegram_chat_id`).

### Запуск

- `start_notifier.bat` — тихий режим, только Telegram (то, что стоит в автозапуске).
- `start_notifier_sound.bat` — то же самое + короткий звуковой сигнал через
  динамики при каждом реальном переходе (когда вы сами сидите за ПК).
- Автозапуск при входе в Windows: `install_autostart.ps1` (щёлкнуть правой
  кнопкой → "Запустить с помощью PowerShell"). Убрать: `uninstall_autostart.ps1`.

Сообщение шлётся ТОЛЬКО при смене статуса (появились/пропали), не на каждой
проверке — канал не спамится.

### Защита от ложных срабатываний

Сайт время от времени показывает интерактивную Cloudflare-проверку
("verifying you are human" и подобные). Если бы код просто проверял "нет
фразы про отсутствие мест → значит места есть", такая страница читалась бы
как ложное "места появились". Поэтому `notifier.py` сначала
проверяет: страница похожа на настоящую (минимальная длина текста + есть
`required_phrases`) — и только потом делают вывод о наличии мест. Если
страница не прошла эту проверку — цикл просто пропускается, без уведомления
и без изменения статуса.

`notifier.py` полностью самостоятелен — работает локально, без каких-либо
облачных аккаунтов. Работает только пока включён ваш ПК и запущен скрипт
(см. автозапуск выше).

## watch.py — личный сигнал для самостоятельного бронирования

Для сценария "я сам сижу и жду, чтобы успеть кликнуть кнопку записи" — см.
[README.txt](README.txt). Требует вход через Дія/BankID в вашем обычном,
уже открытом Chrome (использует его через CDP-отладку), и НЕ бронирует за
вас — только сигналит, когда пора самому кликнуть.

## Требования

- Windows (winsound, Планировщик заданий для автозапуска).
- Python 3.10+.
- Google Chrome (для `watch.py`) или просто Playwright Chromium, который
  ставится через `playwright install chromium` (для `notifier.py`).
