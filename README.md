# pasport-watcher

Личный сигнал о появлении талонов (мест в электронной очереди) на сайтах
паспортных сервисных центров вида `<город>.pasport.org.ua` (ДП «Документ» —
Прага, Валенсия и другие). Скрипт сам НЕ бронирует — только громко сигналит
и показывает окно поверх всех программ, чтобы вы успели сами кликнуть в
открытой вкладке.

## Что это

`watch.py` подключается к вашему ОБЫЧНОМУ, уже открытому Chrome (не к
отдельному пустому профилю — так сайт проходит проверку Cloudflare, как при
обычном заходе руками), периодически обновляет страницу записи и следит, не
пропала ли фраза про отсутствие талонов. Как только текст меняется — громко
пищит и показывает окно поверх всех программ.

Требует вход через Дія.Підпис или BankID НБУ в вашем обычном Chrome (страница
со списком доступных дат видна только после входа).

## Установка

```bash
pip install -r requirements.txt
```

## Настройка и запуск

Полная пошаговая инструкция — в [README.txt](README.txt): открытие Chrome с
отладочным портом, разовый вход и калибровка фраз, запуск наблюдения.

### Под другой город

В `config.json` поменяйте `watch_url` на страницу электронной очереди нужного
города (`https://<город>.pasport.org.ua/solutions/e-queue`), затем
откалибруйте `unavailable_phrases` — откройте страницу в браузере и
скопируйте ТОЧНУЮ фразу, которая написана, когда мест нет (обычно что-то
вроде "Наразі всі місця зайняті" / "спробуйте в інший час").

## Требования

- Windows (используется `winsound` и локальный Chrome с отладочным портом).
- Python 3.10+.
- Google Chrome.
